# Packet 34 — pre-Madeira implementation checklist

## Objective
Assemble the exact checklist that must be green before we should reasonably begin broader Madeira implementation beyond the first slice.

## Why this matters
Madeira is a high-ambition target. We should know what minimum infrastructure/tooling confidence we require before broadening implementation effort.

## Mode
BLOCKER_MODE

## Success condition
- one concrete checklist exists
- each checklist item is tied to a real proof command or artifact
- checklist distinguishes “must-have before broad Madeira work” from “nice-to-have later”

## In scope
- current V3 readiness evidence
- Madeira audit evidence
- validator/probe/docs/tooling status as prerequisites

## Out of scope
- implementing the checklist items
- broader Madeira feature design

## Verification required
- checklist items must be evidence-backed

## Reporting format
Report the checklist with required proofs and a clear threshold for “ready to broaden Madeira work.”
